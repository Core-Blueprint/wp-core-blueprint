# TL-1C-A — Provider-safe Preview API v1 (SOURCE CANDIDATE)

Status: contract/transport source candidate only. No native Mail/Reports render adapter or shared preview UI yet. FRG-04 HOLD.

- Opt-in interface: `TemplatePreviewSourceInterface` extends unchanged `TemplateSourceInterface`. Constant `API_VERSION=1`; `can_preview(template_id, actor_id)`; `render_preview(template_id, expected_version, actor_id): ?TemplatePreview`. The owning provider MUST enforce current record revision, per-item ACL, synthetic-data-only rendering and no remote I/O. Base cannot safely inspect a provider's internal data provenance.
- Response object: `TemplatePreview(version, html)`, <=65,536 UTF-8 bytes, matching metadata revision, strict inert HTML fragment from an allowlist. Disallows links, images, iframes, SVG, CSS stylesheet elements, scripts, forms, all URL-bearing attributes and altered CSS. There are deliberately **no media assets in API v1**. Review as separate security delta if required.
- `POST /core-blueprint/v1/template-library/preview` accepts **exactly** `{source,templateId,version,contextEpoch}`, max 768 request bytes; valid WP REST nonce; logged-in actor; global `manage_options` OR verified short-lived Designer scope. Does not accept documents or preview HTML from the browser. `contextEpoch` is only stale-reply correlation, never authorization. Base Registry checks registered enabled source, provider pair, live browse/view/preview authorization before **and after** rendering, and output object/version; failures give generic refusal. Response is no-store.
- `/sources` adds only `previews:[1]` or `[]` (capability hint); `/templates` remains metadata-only without HTML or per-document loading.
- Scope token currently verifies user/site/session, registered source, active Designer resource authority, 15-minute TTL and matching extension/Designer. No client-selectable role or provider trust.
- TL-1C-C MUST render returned fragment **only** inside opaque sandboxed iframe `sandbox=""` with deny-all CSP embedded ahead of any fragment markup (`default-src 'none'; img-src 'none'; connect-src 'none'; media-src 'none'; font-src 'none'; object-src 'none'; form-action 'none'; base-uri 'none'; script-src 'none'; style-src 'unsafe-inline'`). No `allow-same-origin`, scripts, navigation or external network. Never use parent DOM `innerHTML`. Escape closes and restores focus; discard responses from older epochs. This UX is NOT delivered by TL-1C-A.
- Native Mail TL-1C-B must explicitly construct a safe fragment from the canonical ProjectRenderer with constants/synthetic bindings only. Native Saved Mail must enforce per-record store revision/actor ACL. Native Reports must bypass `DesignerPreview::preview_report()` archived-snapshot fallback and compile an explicitly fake report fixture only; never use real site name, URL, user or archived data.
- Negative coverage: missing/expired/tampered scope; wrong source/resource/type; cross-user; wrong/stale version; provider disabled/throwing/revoked; injected HTML, CSS URLs, media, oversized payload; global vs scoped; metadata no content; no mutation. Full WordPress/runtime/browser and v1 provider conformance remain gates for TL-1C-B/C/D.
- No new datastore, generic renderer, network thumbnailer or changes to Apply/Save/Exit Guard/History. Parallel portability/exporter changes are outside this patch.
